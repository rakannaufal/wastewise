# WasteWise

WasteWise helps residents identify household waste from a photo, receive an automatic ML category, capture automatic location evidence, and follow up with administrators. Web and mobile share a twelve-class taxonomy from the user-provided `garbage_classification/` dataset.

The product is an operational tool, not a marketing website. The first useful action is classifying a photo or creating a report. Administrators review the report queue and change status. Guidance is informational; local collection rules still apply.

The dataset source was confirmed by the user as Kaggle `mostafaabla/garbage-classification`. Local inventory is 15,515 JPEG images across twelve folders. Preserve the original images and audit duplicates before splitting. Measured model performance must be reported independently from application completeness.

Public product name: WasteWise. Interface language: Indonesian. Code and identifiers: English. Do not invent impact metrics, testimonials, collection partners, or model accuracy.
