- Dataset and the twelve example JPEGs: [Garbage Classification, Mostafa Abla](https://www.kaggle.com/datasets/mostafaabla/garbage-classification). Kaggle metadata retrieved 2026-11-02 states **Database: Open Database, Contents: © Original Authors**. Image copyrights are not transferred by this project. The local dataset archive is a handoff copy of user-supplied files, not a declaration that unrestricted public redistribution is permitted.
- MobileNetV2 ImageNet weights: torchvision official `MobileNet_V2_Weights.DEFAULT`; see the [torchvision model documentation](https://pytorch.org/vision/stable/models/generated/torchvision.models.mobilenet_v2.html) and upstream terms. Pretraining data differs from the WasteWise dataset.
- Plus Jakarta Sans: [SIL Open Font License 1.1](https://github.com/tokotype/PlusJakartaSans/blob/master/OFL.txt), distributed through `@fontsource-variable/plus-jakarta-sans`. Retain the license when redistributing fonts.
- Lucide: ISC license. Expo vector icons/Ionicons and other libraries retain their upstream licenses. Exact package versions appear in lockfiles.

No blanket license is assigned to user-supplied SPEC, dataset images, model pretraining material, or the entire repository. Select a code license before public distribution.
