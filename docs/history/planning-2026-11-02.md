## Format catatan fase berikutnya

Tambahkan entri tanpa menghapus bukti historis:

```text
Tanggal dan fase:
Source revision atau working tree yang diuji:
Lingkungan, OS, versi runtime:
Perubahan:
Perintah persis dan direktori kerja:
Hasil aktual, exit code, durasi jika diukur:
Lokasi log atau artefak:
Gate: PASS / FAIL / NOT RUN
Kendala yang memerlukan akses eksternal:
Pekerjaan independen yang dapat dilanjutkan:
Langkah berikutnya:
```

`PASS` memerlukan bukti eksekusi. Keberadaan file saja tidak membuktikan aplikasi bekerja, training selesai, atau kualitas model memenuhi target.
